# Shabab Ahmed Portfolio Website

A premium, interactive, and high-performance portfolio website built using Next.js 15, React, Tailwind CSS, Framer Motion, and Three.js/GSAP animations. The project is designed to run completely offline on a local server.

## Run Locally

**Prerequisites:** Node.js (v18+ recommended)

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Set up local environment configuration:**
   Copy the example environment file to `.env.local`:
   ```bash
   cp .env.example .env.local
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open the browser:**
   Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

## Key Features

- **Liquid Metal Shader Background**: Interactive WebGL shader effect in the hero section.
- **Micro-Animations**: Smooth, responsive interactions using Framer Motion and GSAP.
- **Theme Toggle**: Easy switching between elegant light and luxury dark modes.
- **Spotlight Cards**: Premium hover effects matching the color themes.
